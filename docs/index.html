Your Personal AI Companion — Free, Open Source, and Beautiful

Features

AI Chat

Seamless conversation with AI models via configurable backend endpoints.

Easy Config

Switch between different AI providers and manage API keys effortlessly.

Secure

API keys stored securely using Android Keystore. Your data stays on your device.

Material You

Beautiful Material Design 3 interface with dynamic theming support.

Dark Mode

Full support for system dark and light themes.

No Tracking

100% free and open source. No ads, no analytics, no tracking.

Build from Source

pAI is open source! You can build it yourself:

git clone https://github.com/lalithchary/pAI.git
cd pAI
./gradlew assembleRelease
